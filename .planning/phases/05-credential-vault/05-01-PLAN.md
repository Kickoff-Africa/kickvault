  <action>
1. Install express-rate-limit: `npm install express-rate-limit@^8`

2. Create `src/services/audit.service.ts`:
   - Single export: `createAuditLog({ userId, action, targetType, targetId, ipAddress?, userAgent?, metadata? })`
   - action and targetType are plain strings (NOT enums — the schema uses String, not enum)
   - Fire-and-forget style (returns Promise<void>)
   - Uses `prisma.auditLog.create({ data: params })`

3. Create `src/modules/credentials/credentials.validation.ts`:
   - `createCredentialSchema`: z.object with friendlyName (1-255), systemHost (1-255), username (1-255), secret (min 1), expiresAt (z.string().datetime().optional())
   - `updateCredentialSchema`: all fields optional EXCEPT at least one must be present (use .refine). expiresAt should be `.nullable().optional()` to allow clearing it

4. Create `src/modules/credentials/credentials.service.ts`:

   CRITICAL: `encrypt()` and `decrypt()` from `src/lib/crypto.ts` are SYNCHRONOUS — do NOT await them.
   CRITICAL: `decrypt()` takes a single `EncryptedData` object `{ encryptedValue, iv, authTag, keyVersion }`, NOT separate params.

   Define `SAFE_CREDENTIAL_SELECT` constant — includes id, friendlyName, systemHost, username, expiresAt, createdById, createdAt, updatedAt. NEVER includes encryptedValue, iv, authTag, keyVersion, deletedAt.

   Functions:
   - `createCredential(data, createdById)`: encrypt(data.secret) -> prisma.credential.create with encrypted fields + createdById -> grantCredentialAccess(id, createdById, 'MANAGE') -> return safe credential (re-select with SAFE_CREDENTIAL_SELECT or just omit encrypted fields from response)
   - `listCredentials(userId, userRole)`: If SUPER_ADMIN or MANAGER, find all where deletedAt is null. Otherwise, find where deletedAt is null AND access.some({ userId }). Always use select: SAFE_CREDENTIAL_SELECT
   - `getCredential(id, userId, userRole)`: checkCredentialAccess(userId, userRole, id, 'VIEW') -> findFirst where id AND deletedAt null with SAFE_CREDENTIAL_SELECT -> throw NotFoundError if not found
   - `updateCredential(id, data, userId, userRole)`: checkCredentialAccess(userId, userRole, id, 'EDIT') -> build update fields (if data.secret provided, encrypt it and include encryptedValue/iv/authTag/keyVersion; also include friendlyName/systemHost/username/expiresAt if provided) -> prisma.credential.update with select SAFE_CREDENTIAL_SELECT -> catch P2025 throw NotFoundError
   - `deleteCredential(id, userId, userRole)`: checkCredentialAccess(userId, userRole, id, 'MANAGE') -> prisma.credential.update where id AND deletedAt null, set deletedAt to new Date() -> catch P2025 throw NotFoundError
   - `revealCredential(id, userId, userRole, ipAddress?, userAgent?)`: checkCredentialAccess(userId, userRole, id, 'VIEW') -> findFirst where id AND deletedAt null, select encrypted fields only -> throw NotFoundError if not found -> createAuditLog({ userId, action: 'REVEAL', targetType: 'CREDENTIAL', targetId: id, ipAddress, userAgent }) BEFORE decrypt -> decrypt({ encryptedValue, iv, authTag, keyVersion }) -> return plaintext string

   Import grantCredentialAccess from `../credential-access/credential-access.service.js`
   Import checkCredentialAccess from `../../middleware/requireResourceAccess.js`
   Import encrypt, decrypt from `../../lib/crypto.js`
   Import createAuditLog from `../../services/audit.service.js`

5. Create `src/modules/credentials/credentials.controller.ts`:
   Thin controller pattern — Zod parse + service call + response. No business logic.
   - create: parse body with createCredentialSchema, call createCredential, return 201 with { credential }
   - list: call listCredentials with req.user.id and req.user.role, return 200 with { credentials }
   - getOne: call getCredential with req.params.id (as string), return 200 with { credential }
   - update: parse body with updateCredentialSchema, call updateCredential, return 200 with { credential }
   - remove: call deleteCredential, return 204 no body
   - reveal: call revealCredential with id, userId, userRole, req.ip, req.headers['user-agent'], return 200 with { secret }

   Express 5: cast req.params.id as string

6. Create `src/modules/credentials/credentials.routes.ts`:
   - Import authenticate middleware
   - Import rateLimit from 'express-rate-limit'
   - Create revealRateLimit: windowMs 60000, max 10, keyGenerator req => req.user!.id, standardHeaders 'draft-7', legacyHeaders false, message { error: 'Too many reveal requests, please try again later' }
   - Routes:
     POST   /api/credentials              -> authenticate, create
     GET    /api/credentials              -> authenticate, list
     GET    /api/credentials/:id          -> authenticate, getOne
     PATCH  /api/credentials/:id          -> authenticate, update
     DELETE /api/credentials/:id          -> authenticate, remove
     POST   /api/credentials/:id/reveal   -> authenticate, revealRateLimit, reveal
   - Export credentialRoutes router
