  <action>
Create `src/modules/dashboard/` directory with 4 files following the established module pattern.

**dashboard.validation.ts:**
- Export `dashboardQuerySchema` as `z.object({ expiring_threshold: z.coerce.number().int().min(1).max(365).default(30) })`
- Export `DashboardQuery` type from the schema

**dashboard.service.ts:**
- Import `prisma` from `../../config/database.js`
- Export `getDashboardStats(thresholdDays = 30)` function
- Compute `cutoff = new Date()` then `cutoff.setDate(cutoff.getDate() + thresholdDays)` and `now = new Date()`
- Use `Promise.all()` with 4 parallel queries:
  1. `prisma.asset.count({ where: { deletedAt: null } })` -> totalAssets
  2. `prisma.credential.count({ where: { deletedAt: null } })` -> totalCredentials
  3. `prisma.credential.count({ where: { deletedAt: null, expiresAt: { lte: cutoff, gte: now } } })` -> expiringCredentials
  4. `prisma.auditLog.findMany({ orderBy: { createdAt: 'desc' }, take: 10, include: { user: { select: { id: true, email: true, name: true } } } })` -> recentActivity
- Return `{ totalAssets, totalCredentials, expiringCredentials, recentActivity }`

**dashboard.controller.ts:**
- Import `parseQuery` helper (copy the pattern from audit-logs.controller.ts: a function that wraps Zod parse and converts ZodError to ValidationError)
- Import `dashboardQuerySchema` from `./dashboard.validation.js`
- Import `getDashboardStats` from `./dashboard.service.js`
- Export async `stats(req, res)` that parses `req.query` with dashboardQuerySchema, calls `getDashboardStats(query.expiring_threshold)`, and responds with `res.json({ ...result })`

**dashboard.routes.ts:**
- Import Router from express
- Import `authenticate` from `../../middleware/authenticate.js`
- Import `requireRole` from `../../middleware/requireRole.js`
- Import `* as dashboardController` from `./dashboard.controller.js`
- Create router, register `GET /api/dashboard/stats` with `authenticate, requireRole('MANAGER'), dashboardController.stats`
- Export `{ router as dashboardRoutes }`

All imports must use `.js` extension (ESM/Node16 convention).
