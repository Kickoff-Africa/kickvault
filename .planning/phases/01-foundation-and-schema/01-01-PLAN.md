<task type="auto">
  <name>Task 2: Create application core — env config, logger, database, errors, middleware, health routes, app, and server</name>
  <files>

  <action>
    Create all source files following the exact patterns from the research document:

    **src/config/env.ts** — Zod environment validation:
    - Import `dotenv/config` (side-effect import, loads .env file)
    - Define `envSchema` with z.object containing:
      - `NODE_ENV`: enum ['development', 'production', 'test'], default 'development'
      - `PORT`: z.coerce.number().int().positive().default(3000)
      - `DATABASE_URL`: z.string().url()
      - `MASTER_ENCRYPTION_KEY`: z.string().length(64).regex(/^[0-9a-fA-F]+$/) with descriptive messages
      - `LOG_LEVEL`: enum ['fatal','error','warn','info','debug','trace'], default 'info'
    - safeParse process.env, log errors and exit(1) on failure
    - Export typed `env` object and `Env` type

    **src/config/database.ts** — PrismaClient singleton:
    - Use `globalThis` pattern to store single PrismaClient instance
    - Only assign to globalThis in non-production (prevents hot-reload connection exhaustion)
    - Export `prisma`

    **src/lib/logger.ts** — Pino logger:
    - Create pino instance using `env.LOG_LEVEL`
    - Use pino-pretty transport in development only
    - Export `logger`

    **src/lib/errors.ts** — Custom error classes:
    - `AppError` extends Error with `statusCode` (number) and `isOperational` (boolean, default true)
    - `NotFoundError` extends AppError with statusCode 404
    - `ValidationError` extends AppError with statusCode 400

    **src/middleware/errorHandler.ts** — Global error handler:
    - 4-argument Express error middleware signature
    - Log error with logger.error including path and method
    - Return statusCode from AppError, or 500 for unexpected errors
    - In production, hide internal error messages (return "Internal Server Error")
    - Return JSON: `{ error: { message, statusCode } }`

    **src/modules/health/health.routes.ts** — Health check endpoints:
    - `GET /health`: Returns 200 with `{ status: "ok", uptime: process.uptime(), timestamp: new Date().toISOString() }`
    - `GET /health/ready`: Runs `prisma.$queryRaw\`SELECT 1\`` — returns 200 with `{ status: "ready", database: "connected", timestamp }` on success, 503 with `{ status: "not_ready", database: "disconnected", timestamp }` on failure
    - Export `healthRoutes` router

    **src/app.ts** — Express application:
    - Create Express 5 app
    - Mount middleware in order: helmet(), cors(), pinoHttp({ logger }), express.json()
    - Mount healthRoutes at root level (`app.use(healthRoutes)`)
    - Mount errorHandler as last middleware
    - Export `app`

    **src/server.ts** — HTTP server with graceful shutdown:
    - Import app, env, prisma, logger
    - `app.listen(env.PORT)` with startup log message
    - Graceful shutdown function handling SIGTERM and SIGINT
    - Close HTTP server, disconnect Prisma, exit 0
    - Force exit after 10 seconds timeout

    IMPORTANT: All imports must use `.js` extensions (ESM requirement with Node16 module resolution). Example: `import { env } from '../config/env.js'`
  </action>
