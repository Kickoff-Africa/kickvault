  <action>
    Create `prisma/schema.prisma` with the exact schema from the research document. The schema has 6 model groups:

    **Generator and datasource:**
    - generator: prisma-client-js
    - datasource: postgresql, url from env("DATABASE_URL")

    **Enums (4):**
    - `Role`: SUPER_ADMIN, MANAGER, MEMBER, VIEWER
    - `AssetCategory`: HARDWARE, SOFTWARE, DIGITAL, INTANGIBLE
    - `AssetStatus`: ACTIVE, MAINTENANCE, RETIRED, LOST
    - `PermissionLevel`: VIEW, EDIT, MANAGE

    **Model Group 1 — User:**
    - `User` model with: id (cuid), email (unique), name, passwordHash (@map password_hash), role (default MEMBER), isActive (default true), failedAttempts (default 0), lockedUntil (DateTime?), lastLoginAt (DateTime?), deletedAt (DateTime?), createdAt, updatedAt
    - Relations: sessions, credentials (CredentialCreator), assets (AssetCreator), credentialAccess, assetAccess, auditLogs
    - @@map("users")

    **Model Group 2 — Session:**
    - `Session` model with: id (cuid), userId, refreshToken (unique), userAgent?, ipAddress?, expiresAt, lastActiveAt (default now()), createdAt
    - Relation to User with onDelete: Cascade
    - @@index on userId and expiresAt
    - @@map("sessions")

    **Model Group 3 — Credential:**
    - `Credential` model with: id (cuid), friendlyName, systemHost?, username?, encryptedValue, iv, authTag, keyVersion (default 1), expiresAt?, deletedAt?, createdById, createdAt, updatedAt
    - Relation to User via createdById
    - Relation to CredentialAccess[]
    - @@index on createdById, expiresAt, deletedAt
    - @@map("credentials")

    **Model Group 4 — Asset:**
    - `Asset` model with: id (cuid), assetId (unique), name, category (AssetCategory), status (default ACTIVE), location?, notes?, deletedAt?, createdById, createdAt, updatedAt
    - Relation to User via createdById
    - Relation to AssetAccess[]
    - @@index on assetId, category, status, deletedAt
    - @@map("assets")

    **Model Group 5 — ACL Join Tables:**
    - `CredentialAccess` with: id (cuid), userId, credentialId, permission (default VIEW), grantedAt
    - @@unique([userId, credentialId]), @@index([credentialId])
    - @@map("credential_access")
    - `AssetAccess` with: id (cuid), userId, assetId, permission (default VIEW), grantedAt
    - @@unique([userId, assetId]), @@index([assetId])
    - @@map("asset_access")
    - Both have onDelete: Cascade on User and resource relations

    **Model Group 6 — AuditLog:**
    - `AuditLog` with: id (cuid), action (String), targetType, targetId?, userId, ipAddress?, userAgent?, metadata (Json?), createdAt
    - NO updatedAt field — append-only by design. Add a comment explaining this.
    - @@index on userId, (targetType + targetId), action, createdAt
    - @@map("audit_logs")

    Use `@map("snake_case")` for all multi-word column names. Use `@@map("table_name")` for all models. Add section separator comments between model groups for readability.
  </action>
