**audit-logs.validation.ts:**

Create Zod schemas for query parameters. Follow existing project patterns (z.coerce for numbers, z.string().datetime() for dates).

```typescript
import { z } from 'zod';

export const listAuditLogsQuerySchema = z.object({
  cursor: z.string().optional(),
  limit: z.coerce.number().int().min(1).max(100).default(50),
  action: z.enum(['CREATE', 'UPDATE', 'DELETE', 'REVEAL']).optional(),
  userId: z.string().optional(),
  startDate: z.string().datetime().optional(),
  endDate: z.string().datetime().optional(),
});

export type ListAuditLogsQuery = z.infer<typeof listAuditLogsQuerySchema>;

export const exportAuditLogsQuerySchema = z.object({
  action: z.enum(['CREATE', 'UPDATE', 'DELETE', 'REVEAL']).optional(),
  userId: z.string().optional(),
  startDate: z.string().datetime().optional(),
  endDate: z.string().datetime().optional(),
});

export type ExportAuditLogsQuery = z.infer<typeof exportAuditLogsQuerySchema>;
```

**audit-logs.service.ts:**

Implement `listAuditLogs()` with cursor pagination and `exportAuditLogsCsv()`:

1. `listAuditLogs(params)`:
   - Build `where` clause from optional filters (action, userId, startDate->gte, endDate->lte on createdAt)
   - Use `prisma.auditLog.findMany` with `orderBy: { createdAt: 'desc' }`, `take: limit + 1`
   - If cursor provided: `cursor: { id: cursor }, skip: 1`
   - Include `user: { select: { id: true, email: true, name: true } }`
   - Determine `hasMore` from `logs.length > limit`, slice to `limit`, extract `nextCursor`
   - Return `{ items, nextCursor, hasMore }`

2. `exportAuditLogsCsv(params)`:
   - Build same `where` clause from filters
   - Fetch up to 10,000 rows with same include
   - Convert to CSV string using `escapeCsv()` helper
   - CSV columns: ID, Timestamp, User Email, User Name, Action, Target Type, Target ID
   - Return the CSV string

3. `escapeCsv(value: string)`:
   - If value contains comma, double-quote, or newline, wrap in double quotes and escape internal double quotes
   - Otherwise return as-is

Use `import { prisma } from '../../config/database.js'` and `import { Prisma } from '@prisma/client'` for types. All relative imports use `.js` extension.
