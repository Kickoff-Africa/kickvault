**credential-access.service.ts:**
- Import `prisma` from `../../config/database.js`, `NotFoundError` from `../../lib/errors.js`
- Import `PermissionLevel` from `@prisma/client`
- `grantCredentialAccess(credentialId: string, userId: string, permission: PermissionLevel)`:
  1. `prisma.credential.findFirst({ where: { id: credentialId, deletedAt: null } })` — throw `NotFoundError('Credential not found')` if null
  2. `prisma.user.findFirst({ where: { id: userId, deletedAt: null, isActive: true } })` — throw `NotFoundError('User not found')` if null
  3. `prisma.credentialAccess.upsert({ where: { userId_credentialId: { userId, credentialId } }, create: { userId, credentialId, permission }, update: { permission } })`
  4. Return the upserted record
- `revokeCredentialAccess(credentialId: string, userId: string)`:
  1. Verify credential exists (same findFirst as above, throw NotFoundError if null)
  2. Try `prisma.credentialAccess.delete({ where: { userId_credentialId: { userId, credentialId } } })`
  3. Catch Prisma P2025 (record not found) and throw `NotFoundError('Access entry not found')`
- `listCredentialAccess(credentialId: string)`:
  1. Verify credential exists (same findFirst, throw NotFoundError if null)
  2. `prisma.credentialAccess.findMany({ where: { credentialId }, include: { user: { select: { id: true, email: true, name: true } } } })`
  3. Return the array

**src/middleware/requireResourceAccess.ts:**
```typescript
import { PermissionLevel } from '@prisma/client';
import { prisma } from '../config/database.js';
import { ForbiddenError } from '../lib/errors.js';

const PERMISSION_HIERARCHY: Record<PermissionLevel, number> = {
  VIEW: 1,
  EDIT: 2,
  MANAGE: 3,
};

export async function checkCredentialAccess(
  userId: string,
  userRole: string,
  credentialId: string,
  requiredPermission: PermissionLevel,
): Promise<void> {
  if (userRole === 'SUPER_ADMIN' || userRole === 'MANAGER') return;
  const access = await prisma.credentialAccess.findUnique({
    where: { userId_credentialId: { userId, credentialId } },
  });
  if (!access) throw new ForbiddenError();
  if (PERMISSION_HIERARCHY[access.permission] < PERMISSION_HIERARCHY[requiredPermission]) throw new ForbiddenError();
}

export async function checkAssetAccess(
  userId: string,
  userRole: string,
  assetId: string,
  requiredPermission: PermissionLevel,
): Promise<void> {
  if (userRole === 'SUPER_ADMIN' || userRole === 'MANAGER') return;
  const access = await prisma.assetAccess.findUnique({
    where: { userId_assetId: { userId, assetId } },
  });
  if (!access) throw new ForbiddenError();
  if (PERMISSION_HIERARCHY[access.permission] < PERMISSION_HIERARCHY[requiredPermission]) throw new ForbiddenError();
}
```

Note: ForbiddenError() is called with NO message argument — this matches the established pattern from Phase 3 (never disclose the reason for access denial).
