**credential-access.test.ts test cases (minimum 8):**

`describeWithDb('ACL-01/ACL-03: Credential access management', () => { ... })`

1. **"SUPER_ADMIN can grant VIEW access to a credential (201)"** — Create admin + target user + credential. POST `/api/credentials/:credentialId/access` with `{ userId: targetUser.id, permission: 'VIEW' }`. Expect 201. Expect `res.body.access` to have `userId`, `credentialId`, `permission: 'VIEW'`.

2. **"MANAGER can grant access to a credential (201)"** — Create manager + target user + credential. POST with manager's token. Expect 201.

3. **"granting again with different permission updates it (upsert)"** — Grant VIEW first, then grant EDIT to same user+credential. Expect 201 both times. Second response should have `permission: 'EDIT'`. Verify only 1 record in DB: `prisma.credentialAccess.count({ where: { credentialId, userId } })` returns 1.

4. **"default permission is VIEW when not specified"** — POST with `{ userId: targetUser.id }` (no permission field). Expect 201 with `permission: 'VIEW'`.

5. **"list access returns entries with user email and name (200)"** — Grant access to 2 different users. GET `/api/credentials/:credentialId/access`. Expect 200. Expect `res.body.access` to be an array of length 2. Each entry should have `user.email` and `user.name`.

6. **"revoke access returns 204"** — Grant access, then DELETE `/api/credentials/:credentialId/access/:userId`. Expect 204. Verify record deleted: `prisma.credentialAccess.count(...)` returns 0.

7. **"MEMBER cannot grant access (403)"** — Create member user. POST with member's token. Expect 403.

8. **"VIEWER cannot grant access (403)"** — Create viewer user. POST with viewer's token. Expect 403.

9. **"grant to non-existent credential returns 404"** — POST with `credentialId: 'nonexistent-id'`. Expect 404.

10. **"grant to non-existent user returns 404"** — POST with `{ userId: 'nonexistent-id' }`. Expect 404.

11. **"revoke non-existent access entry returns 404"** — DELETE for user who has no access. Expect 404.

12. **"list access on non-existent credential returns 404"** — GET with `credentialId: 'nonexistent-id'`. Expect 404.
